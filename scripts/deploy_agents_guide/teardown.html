Teardown

Delete everything the lab created, then confirm nothing is left.

./scripts/teardown.sh

It asks once, then deletes in dependency order: the Agent Runtime instance (with its sessions and memories) and the project roles granted to its identity, the online monitor, the access policy and its binding, the gateway's authorization policy, extension and the gateway, the Agent Registry entries, the three Cloud Run services, the image repository and build sources, the logs-based metrics and the dashboard. It ends by listing each resource type and failing if anything is still there:

==> Checking for leftovers ✔ no Agent Runtime instances ✔ no online monitors ✔ no agent gateways ... ✔ no dashboards ==> Nothing left. APIs stay enabled; they cost nothing while unused.

Run ./scripts/teardown.sh --verify-only again later if a delete was still in progress. The script never deletes the project and never disables APIs.

Used a project only for this lab? Deleting the project removes everything at once: gcloud projects delete YOUR_PROJECT_ID.
