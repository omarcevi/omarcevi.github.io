Setup

Do this before the workshop if you can.

Or use Cloud Shell, with nothing to install. Click Open in Cloud Shell. In the dialog, select Trust repo and click Confirm. Cloud Shell copies the repo and opens a tutorial panel next to the editor. It walks you through the setup and every step, and its links open the files for you.

Install uv, the Python package manager the workshop uses:

curl -LsSf https://astral.sh/uv/install.sh | sh  # macOS and Linux; for Windows see the uv docs

Get the code and install it:

git clone https://github.com/omarcevi/coding_agent_workshop.git
cd coding_agent_workshop
uv sync  # installs ADK and pytest into .venv

Get a free Gemini API key at aistudio.google.com/apikey, then save it. The script asks for the key, which doesn't show on screen, and saves it in .env. ADK finds this one file from every agent in the repo.

uv run python scripts/set_key.py

Create the practice project and check that everything works:

uv run reset_workspace.py  # copies the buggy demo project into workspace/
uv run check_setup.py  # every line should say OK

Start the ADK dev UI:

uv run adk web --reload_agents agents

Open localhost:8000 and pick my_agent from Select an app at the top. --reload_agents picks up your code when you save, so you never restart it. Always start it with uv run, so the agent's python -m pytest uses this project's Python.

What's in the repo:

PathWhat it is
agents/my_agent/Your agent. You build it up during the workshop.
agents/step1_hello/ to agents/step4_safe/The finished checkpoint for each step.
demo_project/A tiny shopping cart with two bugs: three of its four tests fail.
workspace/The agent's copy of demo_project/. The agents only touch this folder.
reset_workspace.pyPuts the original buggy project back in workspace/.
