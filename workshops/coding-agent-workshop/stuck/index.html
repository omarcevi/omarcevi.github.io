If you get stuck

Fell behind? Copy the next checkpoint over your agent and carry on:

cp agents/step3_run/agent.py agents/my_agent/agent.py
ProblemFix
Address already in useRun uv run adk web --reload_agents --port 8001 agents and open port 8001.
429 or RESOURCE_EXHAUSTEDToo many calls at once for your project's quota. Wait a minute and try again.
The agent says cart.py doesn't existRun uv run reset_workspace.py.
The agent already fixed everythingRun uv run reset_workspace.py to get the bugs back.
python: command not found inside the agentStart the dev UI with uv run, as in the setup.
check_setup.py fails on the Gemini callRun bash scripts/setup.sh again: it checks the project, billing, credentials and the API.
