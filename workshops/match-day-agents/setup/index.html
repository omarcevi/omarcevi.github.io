Setup

You need a Google Cloud project with billing, the gcloud CLI, and Python 3.11 or newer. A new account gets free trial credits, and they are sufficient. The agents use Gemini through Vertex AI in your project. scripts/setup.sh checks the project, turns on the Vertex AI API, installs the packages with uv, and writes .env.

gcloud auth login
gcloud auth application-default login                # credentials for the agents
gcloud config set project YOUR_PROJECT_ID
git clone https://github.com/omarcevi/trabzonspor_analyst
cd trabzonspor_analyst
bash scripts/setup.sh                                # API, packages and .env
uv run adk web --reload_agents steps

Open http://localhost:8000. Select a step in the dropdown and ask it a question. The events panel shows each tool call and each hand-off. With --reload_agents, ADK loads a file again when you save it.

Cloud Shell. You can also do the workshop in your browser, with nothing to install. Click Open in Cloud Shell. In the dialog, select Trust repo and click Confirm. When Cloud Shell asks to use your credentials, click Authorize. Cloud Shell copies the repo and opens a tutorial panel next to the editor. The tutorial shows each step, and its links open the files and select each BLANK for you.

.env holds four values: GOOGLE_GENAI_USE_VERTEXAI=TRUE, your project, GOOGLE_CLOUD_LOCATION=global and MODEL=gemini-3.8-flash. The first value selects Gemini on Vertex AI. With global, Google spreads the load across regions. The model name is in one place only, matchday/config.py:

The retries are important. One question to step 5 can cause a few dozen model calls. This sometimes causes a 429 error. If the setup does not work on your laptop, use notebook/match_day_agents.ipynb in Colab. It runs the same files, with one cell for each step.

How to fill a blank. On the main branch, the key code of each step is missing. A one-line ✏️ BLANK marker is in its place. When the guide shows a code block with a ✏️ BLANK label, do these steps:

  1. Copy the code block with its copy button.
  2. In the file, select the BLANK line.
  3. Paste the code over it.
  4. Save the file.
  5. Run the step.

If you are late, run uv run python scripts/blanks.py fill 2a. This command pastes the code for BLANK 2a. The demo branch has the full agent team. To see it, run git switch demo.
