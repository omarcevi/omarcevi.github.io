Which recipe when

You need…UseIn this repo
One job, a few tools, some judgementLlmAgent with toolsStep 1 · Scout
Fixed steps, each using the last one's outputSequentialAgent + output_key + {placeholders}Step 2 · Match Prep
Independent work on the same input, in less timeParallelAgent, then a merge stepStep 3 · Scouting Department
A better result after each reviewLoopAgent + a critic + exit_loop + max_iterationsStep 4 · Tribün
Different questions need different specialistsLlmAgent orchestrator + AgentTool + clear descriptionsStep 5 · Technical Director
The same agent on another data sourceMcpToolset instead of local toolsBonus · live MCP

Some rules apply to all the patterns. Let tools do the calculations. Return small dicts, with "not available" instead of null. Make agents with factory functions. Keep the model name in one place.

Try it yourself

Try these changes. Add a compare_players tool to the scout, and ask "Salah mı Franculino mu daha formda?" Give the scouting department a fourth scout. Make the Tribün stricter and count the rounds. Then set max_iterations=1. Use the vague descriptions and see how the director fails. The README of the repo has one challenge for each step.

The code, the data, the Colab notebook and the tests are at github.com/omarcevi/trabzonspor_analyst. The data is a FotMob and ESPN snapshot from 30 October 2026. The injury news can be different now.
